# 飛雷神 Hiraishin

**用轮盘快速操作浏览器：按住 Option / Alt 甩动鼠标、松开执行，切换、整理和复制标签页，把选中文字发送到 ChatGPT / Claude。** 也可点击工具栏轮盘，或配置快捷键。

*Hiraishin: tab history back/forward, tab tidying, and send-selection-to-ChatGPT/Claude for Chrome. Free at launch; runs locally.*

Manifest V3 · 后台与内容脚本为无框架 ES 模块 · 面板与设置页为 React + TypeScript · esbuild 打包

## 安装

需要 Chrome 121 或更新版本，「切回上一 Tab」依赖 `Tab.lastAccessed`。

1. `npm install && npm run build`，产物在 `dist/hiraishin/`。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 **`dist/hiraishin`**（仓库根目录不能直接加载，面板脚本是构建产物）。
4. 在工具栏的扩展菜单中固定 **飛雷神 Hiraishin**；点击图标打开点击式轮盘，右上角设置按钮进入设置页。

已有安装包时，可将 `hiraishin-<version>.zip` 解压后加载。公开下载地址与商店链接在发布后提供。

## 功能

- **工具栏轮盘**：点击扩展图标后直接点击扇区执行，和网页轮盘共用分区配置；关闭右侧标签页需再次确认。网页手势关闭时，工具栏轮盘仍可使用。

### 穿梭

- **访问历史后退 / 前进**：每个窗口独立记录实际激活过的标签页，最多 200 条。使用扩展后退 / 前进只移动游标，不新增记录；到达边界时停留；后退后手动访问新 Tab 会截断前进分支。已关闭或移出窗口的 Tab 从轨迹中移除。
- **切回上一 Tab**：在最近两个标签之间往返，依据每个标签的最近激活时间，因此扩展启用前打开的标签也能切回。它是普通激活，会进入访问历史。

```text
点击访问： A → B → C
历史后退： A ← B ← C
从 C 后退到 B，再手动点击 D：历史变为 A → B → D
前往 Claude（B）并自动返回 A：历史为 A → B → A，可后退到 B
```

### 整理与复制

- **关闭右侧标签页**：以当前 Tab 为锚点，关闭右侧未固定标签，保留固定 Tab 和其他窗口。
- **左移 / 右移 / 移到最左 / 最右**：在同一固定区和同一标签组内移动，到达边界停留。
- **当前 Tab / 当前及左侧 / 当前及右侧移到新窗口**：保留相对顺序和固定状态；完整标签组保留名称与颜色，部分组在新窗口重建。
- **复制标签页**：副本紧贴原 Tab 右侧并激活。
- **复制链接 / 复制为 Markdown**：多选标签时复制全部，否则复制当前 Tab。

### 使用统计

设置页底部的「使用统计」展示累计执行次数、动作明细及入口分布。发起执行即计一次，成功和失败都计数；取消不计，批量关闭计一次。统计仅保存在本机，可清空，当前不上传分析。

### AI 目标与选区传送

- **前往 / 发送到 ChatGPT、Claude**：目标取当前窗口**最左侧**匹配的对话页；没有则在来源 Tab 右侧新建。不跨窗口复用。默认目标是 ChatGPT，可在设置中改。
- **发送**在输入框为空时填入并提交，遇到已有草稿则停留并提示，不覆盖、不混合。只填入不发送与自己复制粘贴价值相近，因此不作为独立动作提供；它只出现在两处：自定义目标声明为「仅填入」时，以及草稿导致发送中止后从待处理选区重试追加。
- **发送后行为**：默认停留在 AI 页面；设置中可开启“发送后返回来源页”，在确认提交后返回，用户已切走则不抢焦点。
- **失败语义**：未登录、正在生成、输入框未就绪、无法确认提交等状态分别提示；失败的选区在面板“待处理选区”中保留最多 30 分钟，可重试填入或复制。
- **入口**：快捷键、右键菜单（选中文字后只列“发送到 X”）、轮盘动作。
- **自定义目标**：设置页可添加任意网站，配置匹配规则、打开地址、能力级别和输入框选择器。

> ChatGPT / Claude 的页面适配基于最近观察到的 DOM 编写，尚未在真实登录页面上完成方案第 12 节“步骤 0”的核对。适配失败时会明确报告，不会伪造“已发送”。

### 网页动作轮盘

在已授权的普通网页中，按住触发键并甩动鼠标即可执行动作。像游戏里的表情轮那样，靠肌肉记忆甩方向，不用瞄准。

- **按住 ⌥ Option**（Windows / Linux 为 **Alt**，键位可在设置页改）**再甩动鼠标**，轮盘立刻在起甩的位置弹出，**往某个方位甩**选中那一瓣，**松开该键或左键**执行，**右键或 Esc** 取消。不需要等待任何延迟。
- **轮盘内的“关闭右侧标签页”需要再次确认**：选中时以琥珀色提示并显示数量，松开或左键只打开确认卡片；再点击“关闭 N 个”才执行。默认聚焦“取消”，Esc、点击卡片外部或切走窗口 / 标签页均取消。如果待关闭标签在确认期间发生变化，需重新打开轮盘确认。
- **只按住不动鼠标，什么都不会出现**。默认用 Option / Alt，单次按住再甩动即可；macOS 的 Command 不再是默认触发键。
- **选择只看方向，不看距离**：甩多远都行，只要越过圆心的死区（40px，远在图标内侧）。手停在死区内就是「未选中」，此时松手什么都不会发生——这是防误触的兜底。
- 轮盘是一圈灰绿色磨砂圆环，使用浅色图标和细亮边。中间保留透明镂空，仅动作名下有一块小底片，避免与网页文字混在一起。每一瓣只有一个图标，选中的那一瓣整片上色。
- 轮盘**几等分**、**每一瓣放哪个动作**都可以配置（4 / 6 / 8 / 12 等分，可以留空瓣）：开启后，设置项下方直接显示轮盘预览、分区数和动作配置。点一瓣选中它，再指定放哪个动作，修改自动保存；关闭网页手势后仍保留配置，工具栏轮盘也仍可使用；两个入口共用分区设置。
- 贴着屏幕边缘召出时，圆心会自动往里挪，保证每个方向都有甩得动的余量。
- 当前不可用的动作（如右侧没有标签页、目标未授权）画成灰色，圆心会说明原因，松手也不会执行。
- 按下其他键会立刻收起，不会执行任何动作——修饰键是组合键的前半段，敲 ⌘+Shift+T 不会误触。
- 面板活在封闭的 Shadow DOM 里：网页的样式进不来，网页的脚本也读不到它。
- 只在网页的顶层框架运行。焦点在嵌入的 iframe 里（例如内嵌视频或编辑器）时，先点一下页面其他位置再触发。
- 只在 HTTP / HTTPS 页面生效；`chrome://` 页面、Chrome 网上应用店等浏览器保留页面上不注入任何脚本。
- 输入框、文本域或可编辑区域聚焦时，Option / Alt 等修饰键仍可按住并甩动触发；字母、数字触发键禁用，避免打字误触。只响应真实按键，网页脚本无法伪造。
- **默认开启**，在设置页直接展示轮盘配置。首次使用需允许网页访问，授权后立即对已打开的网页生效，无需刷新；已保存的关闭设置会保留。

## 快捷键

两类快捷键并存，设置页分别显示**期望配置**与**实际状态**：

| 类型 | 由谁生效 | 适用范围 |
| --- | --- | --- |
| 浏览器快捷键 | Chrome 原生命令，在 `chrome://extensions/shortcuts` 设置 | 所有页面，包括地址栏和内部页 |
| 网页快捷键 | 飛雷神在已授权网页内监听 | 允许注入脚本的 HTTP / HTTPS 网页，可用减号等 Chrome 不支持的按键 |

默认只有历史后退 / 前进绑定了 `Ctrl+,` / `Ctrl+.`（macOS 为实体 Control）。其余 18 个命令默认未绑定，可在 Chrome 中按需配置；命令 ID 见方案附录 A。

在设置页点击“录入”按任意组合：Chrome 支持的组合会引导你去 Chrome 快捷键页设置，并在返回后回读实际绑定；Chrome 不支持的组合（如 `Ctrl+-`）保存为网页快捷键，保存时申请网站访问权限，已打开的网页立即生效，无需刷新。同一组合若已被浏览器快捷键承接，网页内不会重复执行。

Windows / Linux 上网页 `Ctrl+-` 会替代“缩小页面”，可在设置中按网站停用或清除绑定。

## 数据与权限

| 权限 | 用途 |
| --- | --- |
| `tabs`、`tabGroups` | 显示标签标题、按 URL 定位目标、移动时保留标签组 |
| `storage` | 本机保存设置；当前会话保存历史轨迹与待处理选区 |
| `scripting`、`activeTab` | 用户触发时读取真实选区（保留换行）、向目标页注入适配脚本、注册网页快捷键监听 |
| `contextMenus` | 选中文字后的右键菜单 |
| `notifications` | 只在失败、无对象、结果不确定时提示；成功不弹通知 |
| `alarms` | 失败选区的 30 分钟到期清理 |
| `offscreen`、`clipboardWrite` | MV3 的 service worker 没有 DOM，碰不到剪贴板。“复制链接”时后台临时创建一个不可见的扩展页面执行复制，完成即关闭；没有 `clipboardWrite` 时该复制命令会被浏览器拒绝 |
| 可选网站权限 | 网页快捷键 / 网页轮盘需要 HTTP / HTTPS；填入 / 发送需要对应目标网站，均在设置中按需允许 |

设置与访问轨迹只保存在本机；填入 / 发送会按你的操作把选中文字交给目标网站。历史使用 `chrome.storage.session`，后台休眠不丢失，浏览器重启后重新开始。不在无痕模式中运行。

## 开发与验证

```sh
npm run build      # esbuild 打包 ui/ 并复制静态文件到 dist/hiraishin/，同时生成 site/actions.json
npm run dev        # 监听 ui/ 变化重建；在扩展管理页点“重新加载”即可看到
npm test           # 单元测试：历史、Tab 操作、快捷键、传送保护、设置并发保存、本地操作计数
npm run check      # 构建 → manifest 与命令清单一致性、dist 资源引用、语法与样式规则检查 → tsc（src JSDoc checkJs + ui strict）
npm run smoke      # 在 Chrome for Testing 里加载 dist，用 DevTools 协议验证真实行为
npm run shot       # 按 3 倍渲染并截取页面中的某个元素，用于肉眼复核视觉细节
npm run package    # check 后打 dist/hiraishin-<version>.zip
```

`npm run smoke` 需要 Chrome for Testing 或 Chromium（品牌版 Chrome 137 起忽略 `--load-extension`）。默认在 Playwright / Puppeteer 缓存中查找，也可用 `CHROME=/path/to/binary` 指定。它用本地 fixture 页面充当自定义 AI 目标，验证浏览器中的核心流程：历史与标签操作、剪贴板、填入 / 发送与草稿保护、快捷键、轮盘手势和危险操作确认、设置保存与本地统计。它不替代 ChatGPT / Claude 真实登录页验收。

日常修改先运行相关单元测试和 `npm run check`；涉及浏览器交互或准备发布时再运行冒烟。边界条件、权限、并发与计数规则放在单元测试中，冒烟保留真实交互及安全检查，不再重复枚举按键组合或检查旧界面是否消失。尺寸、配色、图标对齐用截图复核，提示延时在相关改动时手动检查。

它**默认有头运行**（会短暂弹出一个浏览器窗口）：无头渲染进程在被派发输入事件后会停止响应 DevTools 协议，测试驱动需保持真实的修饰键状态与前台窗口焦点。`HEADLESS=1 npm run smoke` 可强制无头，但网页动作轮盘那一节在那里跑不了。


## 常见问题

**Hiraishin 的标签历史和浏览器的后退有什么区别？** 浏览器后退在同一个标签页里回到上一个网址；Hiraishin 记录的是你在标签页之间的切换轨迹，每个窗口独立，后退会切回上一个激活过的标签页，像 VS Code 的位置历史。

**怎样用快捷键关闭当前标签右侧的所有标签？** 在 `chrome://extensions/shortcuts` 给“关闭右侧标签页”绑定任意组合键。固定标签和其他窗口不受影响。

**如何把网页上选中的文字直接发送给 ChatGPT 或 Claude？** 选中文字后通过轮盘、快捷键或右键菜单发送。目标是当前窗口最左侧的对话页，没有则在旁边新建；输入框已有草稿时会停下并提示，不覆盖。

**Chrome 扩展快捷键不支持减号，怎么支持 `Ctrl+-`？** Hiraishin 在你授权的网页里监听按键作为“网页快捷键”；地址栏和 Chrome 内部页面仍用原生快捷键或面板。

**标签历史和「切回上一 Tab」有什么区别？** 标签历史是一条带游标的轨迹，同一个标签可以出现多次，支持连续后退 / 前进，后退后再手动切换会截断前进分支。切回上一 Tab 只在最近两个标签之间往返，依据标签的最近激活时间，因此扩展启用前打开的标签也能切回。按最近激活排序的完整列表不在首发范围内。

**快捷键会和其他软件冲突吗，能识别吗？** 分三种情况。扩展内部两个动作用同一组合、以及网页组合被浏览器快捷键承接，设置页会直接标出。默认键被其他扩展占用时，Chrome 回读为空，设置页提示“默认键未生效，可能被其他扩展占用”。被操作系统或浏览器在到达网页前拦截的组合（如 `Cmd+Space`、`Ctrl+T`）无法从代码探测，设置页对已知保留组合给出预警，并提供“试按区”让你现场按键确认按键是否到达网页。

**会上传我的浏览数据吗？** 不会。设置和轨迹只保存在本机；只有你主动填入或发送时，选中的文字才会交给你选择的 AI 网站。

**收费吗？** 当前版本免费，不设 Free / Pro 分层或自定义目标数量限制；收费方案以后另行讨论。没有订阅、云同步或提示词模板。

### 手动验收（真实 Chrome）

- 历史：A → B → C 连续后退 / 前进；后退后手动访问 D；两窗口隔离；停止 service worker 后继续导航。
- 整理：当前 Tab 在中间，含固定 / 分组时移动、关闭右侧、移到新窗口。
- 快捷键：录入 `Ctrl+-` 并接受 / 拒绝授权；在 Chrome 中修改绑定后返回设置页；受限页面、编辑器内按键。
- 目标：多个 Claude Tab 时取最左侧；跨窗口不复用；连续触发不重复开页。
- AI：登录页、生成中、已有草稿、空选区、含换行的代码块；开启返回后 A → B → A 出现在历史中。
- 网页动作轮盘：设置页开启后不刷新页面直接按住 Option / Alt；只按住不动鼠标不出现，甩起来才弹在起甩处；甩向某一瓣即高亮，松开执行；手停在圆心松手什么都不发生；右键与 Esc 取消；贴着屏幕四角召出仍能甩到每个方向；按住 Option / Alt 后再按其他键会取消；输入框聚焦时修饰键加甩动可触发，字母、数字触发键仍禁用；`chrome://extensions` 等保留页面上无反应。
