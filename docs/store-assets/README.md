# 1.0.0 商店素材

中日英截图已于 2026-11-04 生成并逐张目检。界面或文案改动后用 `npm run store:shots` 重拍；上传前确认内容对应最新构建、语言正确。

- `01-settings-<lang>.png`：1280×800，实际设置页；`lang` 为 `zh` / `ja` / `en`。日文截图须反映“首次成功操作开始试用”的最新文案。
- `02-wheel-<lang>.png`：1280×800，在对应语言主页上实际召出的网页轮盘。
- `npm run store:shots` 使用独立 Chrome 配置和发布 manifest 生成上述截图：全新安装（不手动授予任何权限）、官网首页为背景、开两个标签页使「切回上一个」「关闭右侧」为可用状态；脚本会拒绝不是 1280×800 的图。运行时不要有别的无头 Chrome 同时在跑，否则截图会卡住。
- `01-wheel-settings.png` 是 0.2.0 历史截图，不作为 1.0.0 当前界面的验收依据。
- `promo-440x280.png`：可选的 440×280 小宣传图。源文件 `promo.html`；轮盘为宣传示意，不是 AI 发送成功截图。宣传图全语言共用，不能在商店为每种语言单独选择。
- 商店图标使用仓库 `icons/128.png`；至少提供一张 1280×800 或 640×400 的实际截图。

不要把诊断页面、模拟站点发送结果或未经验证的内置 AI 流程用于宣传。参考：[Chrome 商店图像要求](https://developer.chrome.com/docs/webstore/images)（2026-11-04 核对）。提交前在商店预览中检查裁切、文字和最终尺寸。
