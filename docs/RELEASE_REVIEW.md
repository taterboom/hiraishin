# 0.2.0 上线前产品审查

审查日期：2026-09-25。范围：首次使用、轮盘与设置、发送流程、权限与隐私、发布资料、可安装包。未执行商店提交或公开发布。

## 产品判断

主线应收敛为「用轮盘快速执行浏览器动作」：按住 Option / Alt 甩动、松开执行，也可点击工具栏轮盘。标签切换、整理、复制链接和发送选区是轮盘里的动作，不再用旧版“动作面板 + 历史列表”来解释产品。功能范围冻结，优先把首次成功和失败恢复说明清楚。

### 公开上架前必须补齐

1. **真实 ChatGPT / Claude 各跑一轮**：登录、网站授权、选中含换行文字、轮盘发送；已有草稿应保留，生成中不重复发送，失败后可找回选区并重试填入。分别验证默认停留和“发送后返回”。记录日期、浏览器版本、结果；若其中一站不通过，先修复或从首发承诺中去掉。
2. **公开隐私页与支持入口**：将 `site/privacy.html` 放在实际可访问的 HTTPS 地址，填写真实支持邮箱 / 网址与开发者信息，核验主页和下载链接。商店隐私表单按实际处理的数据填写，不能因无自建服务器就声称“不处理用户数据”。
3. **目标系统实机**：若同时面向 Windows / Linux，验证 Alt 按住甩动、组合键取消、释放后菜单、输入框内不触发与权限拒绝路径。未测平台不宣传已验证。

### 提交与安装

- `npm run package` 生成 `dist/hiraishin-0.2.0.zip`。试用时解压，通过 `chrome://extensions` 的“加载已解压的扩展程序”选择含 manifest 的目录；升级后刷新已打开的网页。
- 商店填写内容见 [STORE_LISTING.md](STORE_LISTING.md)，图片见 [store-assets](store-assets/README.md)。不把测试 fixture 或模拟 AI 成功画面当作真实效果截图。
- 本次没有商店提交、公开部署或 Git 提交。仓库未配置 Git remote，也未确定开源许可证；如计划公开源码，另行选择许可证。
