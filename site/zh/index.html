先用上轮盘

按住、甩动、松开

在设置中允许网页访问后，macOS 按住 Option，Windows / Linux 按住 Alt，再甩动鼠标选择动作，松开执行。只按住不动不会弹出，圆心松手不执行；Esc 或右键取消。

你的方向，你的动作

4 / 6 / 8 / 12 等分自由配置，每一瓣可以放入动作或留空。点击工具栏图标也能打开同一套轮盘，用鼠标点击执行。轮盘上的批量关闭会先确认数量，再执行。

它解决什么问题

“刚才那个页面在哪？” → 标签访问历史后退 / 前进

每个窗口独立记录你实际切换过的标签页，像 VS Code 的位置历史一样后退、前进。默认 Ctrl+, / Ctrl+.，也可用 Ctrl+- / Ctrl+Shift+- 作为网页快捷键。后退后手动打开新标签会截断前进分支；到达边界时停留。

“这部分工作结束了” → 关闭右侧标签、移到新窗口

以当前标签为锚点关闭右侧所有未固定标签；把当前标签、当前及左侧或右侧标签一起移到新窗口，标签组的名称和颜色会一并带过去。

“这个动作每次都很麻烦” → 复制标签、移动标签、复制链接

复制标签页、左移 / 右移 / 移到最左最右、复制一个或多个标签的链接（纯文本或 Markdown），全部可绑定快捷键。

“查到一段内容，想立刻交给 AI” → 填入或发送到 ChatGPT / Claude

选中文字，通过轮盘、快捷键或右键，Hiraishin 切换到当前窗口最左侧的对话页（没有则在旁边新建），填入并发送。已有草稿时不会覆盖；未登录、正在生成、无法确认提交时都会明确告诉你。可选“发送后返回来源页”。可配置兼容网站作为自定义目标，需要正确的地址规则和页面选择器。

常见问题

Hiraishin 的标签历史和浏览器的后退有什么区别？

浏览器后退在同一个标签页里回到上一个网址；Hiraishin 记录的是你在标签页之间的切换轨迹，每个窗口独立，后退会切回上一个激活过的标签页。

怎样用快捷键关闭当前标签右侧的所有标签？

在 chrome://extensions/shortcuts 给“关闭右侧标签页”绑定任意组合键。固定标签和其他窗口不受影响。

如何把网页上选中的文字直接发送给 ChatGPT 或 Claude？

选中文字后通过轮盘、快捷键或右键菜单发送。目标是当前窗口最左侧的对话页，没有则新建。输入框已有草稿时会停下并提示。

Chrome 扩展快捷键不支持减号，怎么支持 Ctrl+-？

Hiraishin 在你授权的网页里监听按键作为“网页快捷键”；地址栏和 Chrome 内部页面仍用原生快捷键或面板。

会上传我的浏览数据吗？

不会。设置和轨迹只在本机；只有你主动填入或发送时，选中的文字才会交给你选择的 AI 网站。

安装与开始使用

当前为发布候选版本，Chrome 网上应用店链接将在上架后提供。已取得开发者提供的安装包时：解压 ZIP → 打开 chrome://extensions → 开启开发者模式 → 加载已解压的文件夹。

固定工具栏图标，先试着点击轮盘。进入设置允许网页访问后，即可使用网页手势。网页轮盘不适用于 Chrome 内部页、网上应用店等受限页面；发送到 AI 需要相应网站权限与已登录账号，网站界面变化可能影响适配。
