Hiraishin飛雷神 · CHROME 拡張機能

Option / Alt を押しながら、振って、離す。
ホイールでタブを切り替え、ページを整理し、選択テキストを AI に送れます。

インストールと使い方プライバシー

まずはホイールから

押して、振って、離す

設定でサイトへのアクセスを許可したら、macOS では Option、Windows / Linux では Alt を押しながらマウスを振ってアクションを選び、離すと実行します。キーを押したまま動かさなければ何も表示されず、中心で離しても何も実行されません。Esc キーか右クリックでキャンセルできます。

方向もアクションも自分で決める

ホイールは 4 / 6 / 8 / 12 分割から選べ、各セクターにアクションを入れるか空けておけます。ツールバーのアイコンをクリックしても同じホイールが開き、クリックで実行できます。ホイールからタブをまとめて閉じるときは、閉じる数を表示して確認してから実行します。

こんなときに

「さっきのページはどこ？」→ タブ履歴を戻る / 進む

実際に切り替えたタブをウィンドウごとに記録し、VS Code の移動履歴のように戻ったり進んだりできます。既定のキーは Ctrl+, / Ctrl+. で、Ctrl+- / Ctrl+Shift+- をページ内ショートカットとして使うこともできます。戻ったあとに手動で別のタブを開くと、その先の履歴は切り捨てられます。端まで来たらそこで止まります。

「この作業はここまで」→ 右側のタブを閉じる、新しいウィンドウへ移動

現在のタブを基準に、右側の固定されていないタブをすべて閉じます。現在のタブ、または現在のタブと左側・右側のタブをまとめて新しいウィンドウへ移動でき、タブグループの名前と色も引き継がれます。

「毎回この操作が面倒」→ タブの複製・移動、リンクのコピー

タブの複製、左 / 右 / 先頭 / 末尾への移動、1 つまたは複数のタブのリンクのコピー（プレーンテキストまたは Markdown）。どれもショートカットを割り当てられます。

「見つけた内容をすぐ AI に渡したい」→ ChatGPT / Claude に入力・送信

テキストを選択し、ホイール、ショートカット、または右クリックから実行すると、Hiraishin は現在のウィンドウで一番左にあるチャットタブに切り替え（なければ隣に新しく開き）、入力して送信します。下書きがあれば上書きしません。未ログイン、回答の生成中、送信を確認できないときは、はっきりお知らせします。「送信後に元のページへ戻る」も選べます。互換性のあるサイトをカスタム送信先として設定することもできますが、正しい URL ルールとページのセレクターが必要です。

よくある質問

Hiraishin のタブ履歴とブラウザの「戻る」は何が違いますか？

ブラウザの「戻る」は同じタブの中で前の URL に戻ります。Hiraishin はタブ間の切り替えの軌跡をウィンドウごとに記録し、「戻る」で直前にアクティブだったタブに切り替えます。

現在のタブより右のタブをショートカットでまとめて閉じるには？

chrome://extensions/shortcuts で「右側のタブを閉じる」に好きなキーの組み合わせを割り当てます。固定したタブや他のウィンドウには影響しません。

ページで選択したテキストを ChatGPT や Claude に直接送るには？

テキストを選択し、ホイール、ショートカット、または右クリックメニューから送信します。送信先は現在のウィンドウで一番左にあるチャットタブで、なければ新しく開きます。入力欄に下書きがある場合は止まってお知らせします。

Chrome 拡張機能のショートカットはマイナスキーに対応していませんが、Ctrl+- はどうやって使えるのですか？

アクセスを許可したサイトで Hiraishin がキー入力を受け取り、「ページ内ショートカット」として扱います。アドレスバーや Chrome の内部ページでは、ネイティブショートカットかツールバーのホイールを使ってください。

閲覧データはアップロードされますか？

いいえ。設定とタブ履歴は端末内にのみ保存されます。選択テキストは、あなたが入力や送信を実行したときにだけ、選んだ AI サイトに渡されます。

料金はかかりますか？

すべての機能を 14 日間無料でお試しいただけます。試用期間は、初めて操作が成功したときから始まります。試用終了後は、一度購入するだけで引き続きお使いいただけます。サブスクリプションではありません。試用が終わっても、設定と保留中の内容はそのまま残ります。

インストールと使い方

現在はリリース候補版です。Chrome ウェブストアのリンクは公開後にお知らせします。開発者からインストールパッケージを受け取っている場合は、ZIP を展開 → chrome://extensions を開く → デベロッパー モードをオン → 展開したフォルダを読み込む、の順に進めてください。

ツールバーのアイコンを固定し、まずはクリックでホイールを試してみてください。設定でサイトへのアクセスを許可すると、ページ上でジェスチャーを使えるようになります。ページ内ホイールは Chrome の内部ページやウェブストアなど、制限されたページでは使えません。AI への送信には、そのサイトへのアクセス許可とログイン済みのアカウントが必要です。サイトの画面が変わると、うまく動かなくなることがあります。
