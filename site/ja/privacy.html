プライバシーとデータの取り扱い

飛雷神 Hiraishin は、ホイール、ショートカット、右クリックメニューからブラウザのタブを操作したり、選択テキストを送信したりするための Chrome 拡張機能です。

対象バージョン：1.0.0 · 更新日：2026-11-04

データの取り扱い

この拡張機能には広告がなく、テレメトリも送信しません。使用回数は端末内でのみ集計されます。拡張機能自体が通信する開発者のサーバーはライセンスサービスだけで、通信はライセンスの購入・有効化・確認のためだけに行われます（下の表の「ライセンス」の行をご覧ください。フィードバックページは自分で開いて送信したときだけ使われます。「フィードバック」の行をご覧ください）。閲覧履歴、ページの URL、タイトル、選択テキスト、使用回数がこのサーバーに送られることはありません。タブの情報と選択テキストは端末内で処理されます。「入力」または「送信」を選んだときは、選択テキストが設定した送信先サイトに書き込まれます。「送信」の場合は、さらに入力内容の送信も試みます。

データ用途と保存期間
設定、送信先 URL、ページ内ショートカット現在の Chrome プロファイルの、拡張機能用ローカルストレージに保存されます。変更するか、拡張機能のデータを消去するか、拡張機能をアンインストールするまで保持されます。
使用回数アクションの識別子、呼び出し方法（ホイール・ショートカットなど）ごとの累計実行回数、集計開始日時だけを端末内に保存します。成功・失敗にかかわらずカウントし、個々の操作、ページの URL、タイトル、選択テキストは記録せず、アップロードもしません。設定ページで消去でき、アンインストール時に削除されます。
タブ ID、タイトル、URL、切り替え履歴タブの切り替え・整理と、送信先の特定に使います。切り替え履歴はウィンドウごとに最大 200 件までセッションストレージに記録し、ブラウザを再起動するとリセットされます。
選択したテキストとその取得元送信または入力を実行したときにだけ読み取ります。完了していないタスクは、再試行やコピーのためにセッションストレージに最大 30 分間保持されます。成功すると消去され、ブラウザを再起動すると残りません。バックグラウンド処理が休止している場合、定期的な消去が少し遅れることがあります。
送信先の入力欄とページの状態ログインしているか、下書きがあるか、回答を生成中か、入力と送信に成功したかを判断するために使います。アカウントのパスワードを拡張機能に入力していただく必要はなく、既存の下書きを上書きすることもありません。
ライセンス試用期間の開始日時は端末内に保存されます。購入時、拡張機能はライセンスサービスからランダムな受け取り用の認証情報を取得し、そのダイジェストを支払いとともに Stripe に渡して、支払い後にライセンスキーを受け取れるようにします。支払い、税金、領収書は Stripe が処理します。ライセンスサービスが保存するのは、その支払いの参照番号、支払いに使われたメールアドレス（購入後の問い合わせ確認にのみ使用）、受け取り用認証情報のダイジェスト、ライセンスキーのダイジェストと暗号化したコピーだけです。データベースには IP アドレスを保存しません。有効化と 1 日 1 回の確認では、この記録を読み取るだけで、書き込みは行いません。ライセンスサービスは Cloudflare 上で運用しており、その稼働ログには一部のリクエストについて、IP アドレスとそこから推定されるおおよその所在地が記録されます。このログは障害の調査にのみ使われ、最大 7 日で自動的に削除されます。支払いの記録は、ライセンスの復元と購入後の問い合わせ確認のため、削除のご依頼があるまで保存します。返金後も、返金済みのライセンスが再び有効にならないよう、取り消し済みとして保存します。削除をご希望の場合はお問い合わせフォームからご連絡ください。削除すると、そのライセンスキーは有効化も復元もできなくなります。Stripe が保持する支払い情報の扱いは、Stripe のプライバシーポリシーに従います。受け取り用の認証情報、ライセンスキー、サービスが発行するライセンストークンは端末内に保存されます。このうち受け取り用の認証情報とライセンスキーだけを Chrome の同期ストレージ（chrome.storage.sync）にも保存し、Chrome の同期が有効な場合に再インストール時や別のパソコンで復元できるようにします。ライセンストークンは同期しません。有効化時はライセンスキーを、その後およそ 1 日に 1 回の確認時はライセンストークンをライセンスサービスに送ります。これらのリクエストに閲覧データは含まれません。
キーボードとマウスのイベント設定したページ内ショートカットとホイールのジェスチャーを認識するためだけに使います。ページに埋め込まれたフレーム（Claude の Artifacts や埋め込みデモなど）の中で始めたジェスチャーも対象です。入力内容は保存しません。そうしたジェスチャーの間、開始位置の画面座標は拡張機能の内部でページの最上位フレームに渡され、そこでホイールを表示します。保存も外部への送信もしません。トリガーを文字キーや数字キーにした場合、入力欄の中ではページ内ホイールは起動しません。
フィードバック「欲しい機能を伝える」を開き、そのページであなた自身が送信したときだけ発生します。リンクに含まれるのは製品・バージョン・画面の言語だけです。44san のフィードバックサービス（koe.44san.com、Cloudflare 上で動作）は、入力した内容、任意の返信用メールアドレス、Cloudflare が判定した国 / 地域を保存し、IP アドレスは保存しません。新しいフィードバックはメールと Feishu で開発者に転送されます。フィードバックは削除するまで保存されます。削除を希望する場合は開発者にご連絡ください。

限定的な使用

Hiraishin によるユーザーデータの使用と転送は、限定的な使用（Limited Use）の要件を含む Chrome ウェブストアのユーザーデータに関するポリシーに準拠しています。ユーザーデータは、ここで説明した機能の提供にのみ使用し、販売や広告には使用しません。

第三者のサイト

テキストは、選んだ ChatGPT、Claude、またはカスタムサイトに直接渡され、開発者が受け取ることはありません。第三者のサイトがテキストをどのように保存・利用するかは、そのサイトのプライバシーポリシーとアカウントの設定によります。カスタムサイトはご自身で設定するものです。そのサイトに処理されてもよい内容だけを送信してください。

送信先に下書きがある、ログインしていない、または送信結果を確認できない場合は、拡張機能がお知らせし、必要に応じて保留中の選択テキストを残します。二重送信を防ぐため、送信を確認できなかったときに自動で再送信することはありません。

権限と、あなたができること

  • タブとタブグループ：タブの切り替え・移動・複製・閉じる操作と、移動時のグループの維持に使います。
  • ローカル・セッション・同期ストレージ：設定、タブの切り替え履歴、保留中の選択テキスト、ライセンス情報の保存に使います。同期する範囲は上記のとおりです。
  • スクリプトと現在のタブへのアクセス：操作を実行したときに選択テキストを読み取り、送信先サイトにテキストを入力するために使います。
  • サイトへのアクセス（インストール時に許可）：通常の HTTP / HTTPS ページでページ内ホイールとページ内ショートカットを使えるようにし、選んだ AI サイトへの入力と送信にも使います。ページの内容を読むのは操作を実行したときだけです。Chrome の拡張機能の詳細ページでサイトへのアクセスを絞り込んだり取り消したりでき、その場合これらの機能は再び許可するまで止まります。
  • コンテキストメニュー、通知、アラーム：操作メニューの提供、失敗のお知らせ、期限切れの保留中の内容の消去、定期的なライセンス確認に使います。
  • オフスクリーンドキュメントとクリップボードへの書き込み：実行したリンクのコピー操作に使います。クリップボードを読み取ることはありません。

ページ内ホイールをオフにする、ページ内ショートカットを消去する、保留中の選択テキストを消去する、カスタム送信先を削除する、といった操作ができます。拡張機能をアンインストールすると、そのローカルストレージは削除されます。拡張機能内の記録を消去しても、第三者のサイトにすでに送信した内容は削除されないため、各サイトで管理してください。この拡張機能はシークレット モードでは動作しません。

お問い合わせと更新

プライバシーに関するご質問や削除のご依頼は、お問い合わせフォーム、または Chrome ウェブストアの飛雷神 Hiraishin のページに記載されている開発者の連絡先までお寄せください。データの取り扱いが変わる場合は、拡張機能とあわせてこの説明を更新します。
