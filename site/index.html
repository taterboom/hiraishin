Start with the wheel

Hold, flick, release

Once you allow site access in Settings, hold Option on macOS or Alt on Windows / Linux, flick the mouse toward an action and release to run it. Holding the key without moving shows nothing, and releasing in the center does nothing; press Esc or right-click to cancel.

Your directions, your actions

Split the wheel into 4, 6, 8 or 12 sectors and put an action in each one or leave it empty. Clicking the toolbar icon opens the same wheel, where you click an action to run it. Bulk closing from the wheel shows how many tabs will close and asks you to confirm first.

What it solves

“Where was that page I just had?” → Tab history back / forward

Each window keeps its own record of the tabs you actually switched to, so you can go back and forward like location history in VS Code. The defaults are Ctrl+, / Ctrl+., and Ctrl+- / Ctrl+Shift+- also work as in-page shortcuts. Opening a new tab by hand after going back cuts off the forward branch; at either end it stays put.

“I'm done with this part of the work” → Close tabs to the right, move to a new window

Close every unpinned tab to the right of the current one; move the current tab, or the current tab together with the tabs to its left or right, to a new window, keeping tab group names and colors.

“This takes too many clicks every time” → Duplicate, move and copy links

Duplicate a tab, move it left / right / to the start or end, and copy the links of one or more tabs as plain text or Markdown. Every action can have a shortcut.

“I found something and want AI on it now” → Fill or send to ChatGPT / Claude

Select text and use the wheel, a shortcut or the right-click menu: Hiraishin switches to the leftmost chat tab in the current window (or opens one next to your tab), fills in the text and sends it. An existing draft is never overwritten, and you are told clearly when you are signed out, a reply is still generating, or the submission can't be confirmed. Optionally return to the source page after sending. Compatible websites can be added as custom targets; they need a correct URL rule and page selectors.

FAQ

How is Hiraishin's tab history different from the browser's Back button?

The browser's Back button returns to the previous URL within the same tab. Hiraishin records the trail of tabs you switch between, separately for each window, and going back switches to the tab you had active before.

How do I close all tabs to the right of the current tab with a shortcut?

Open chrome://extensions/shortcuts and assign any key combination to “Close tabs to the right”. Pinned tabs and other windows are not affected.

How do I send selected text on a web page straight to ChatGPT or Claude?

Select the text, then send it from the wheel, a shortcut or the right-click menu. The target is the leftmost chat tab in the current window, or a new one if there is none. If the input box already has a draft, Hiraishin stops and tells you.

Chrome extension shortcuts can't use the minus key. How is Ctrl+- supported?

On sites you have granted access to, Hiraishin listens for the keys itself as “in-page shortcuts”. In the address bar and on Chrome's internal pages, use native shortcuts or the toolbar wheel.

Does it upload my browsing data?

No. Settings and your tab trail stay on your device. Selected text goes to the AI website you chose only when you explicitly fill or send it.

Does it cost anything?

Every feature is free to try for 14 days, starting the first time an action runs successfully. After the trial, a one-time purchase keeps it working; there is no subscription. Your settings and pending selections are kept when the trial ends.

Install and get started

This is a release candidate; the Chrome Web Store link will be added once it is published. If you have an install package from the developer: unzip it → open chrome://extensions → turn on Developer mode → load the unpacked folder.

Pin the toolbar icon and try clicking the wheel first. After allowing site access in Settings, you can use gestures on web pages. The in-page wheel does not work on restricted pages such as Chrome's internal pages or the Chrome Web Store. Sending to AI requires access to that website and a signed-in account, and changes to the website's interface may affect compatibility.
